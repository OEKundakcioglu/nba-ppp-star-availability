# Audited October 25 manuscript

The files in this directory come from `NBA_Method_Audit_Reproducibility.zip`, a later October 25 methodology-reviewed bundle:

- `main.tex`: editable LaTeX source (trailing whitespace normalized only).
- `figure1_raw_absence_onset_rates.pdf`, `figure2_home_road_onsets.pdf`: included figures referenced by the source.

To build, install a compatible LaTeX distribution and run `pdflatex main.tex` twice from this directory. No LaTeX compilation is claimed for this patch.
